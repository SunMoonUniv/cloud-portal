키를 바꾸면 앞으로 만드는 VM에만 들어간다. 이미 있는 VM에는 예전 키가 그대로 있다.

{{- else}}

{{- end}}

키가 없으면: 새로 만들기

포털이 키 쌍을 만들어 공개 키는 등록하고, 개인 키 파일(student-cloud-key)을 한 번만 내려 준다. 포털은 개인 키를 저장하지 않으므로 잃어버리면 새로 만들어야 한다.

내려받은 파일 쓰는 법
  1. Windows: 파일을 C:\Users\내이름\.ssh\ 폴더로 옮긴다(폴더가 없으면 만든다).
    명령 프롬프트에서 ssh -i %USERPROFILE%\.ssh\student-cloud-key ubuntu@유동IP
  2. macOS·Linux: mv ~/Downloads/student-cloud-key ~/.ssh/ && chmod 600 ~/.ssh/student-cloud-key
    ssh -i ~/.ssh/student-cloud-key ubuntu@유동IP

키가 있으면: 공개 키 붙여 넣기

직접 만들려면 명령 프롬프트(Windows 10 이상)나 터미널에서 ssh-keygen -t ed25519을 실행하고, .ssh\id_ed25519.pub 파일 내용을 붙여 넣는다. 그러면 ssh ubuntu@유동IP만으로 접속된다.
